# T1000

Master's thesis repository (LaTeX + supporting Markdown context docs) on data-quality preprocessing. The compiled document is `main.pdf`; sources live in `main.tex`, `content/`, `ads/`, with bibliography in `ArbeitBib.bib` and working notes under `context/`.

## Agent skills

### Issue tracker

Issues and PRDs are tracked as GitHub issues on `thexsteven/T1000` via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, with label strings kept at their defaults (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
